Desenvolvedor Backend / Full Stack

mai/2025 → atual

São Luís, MA · sistemas em produção

  • Inspeção Sanitária de Abatedouros: fiz a primeira versão da API em FastAPI (SQLAlchemy, Alembic, Pydantic v2) e depois migrei o backend para DRF sem perder funcionalidades.   • Relatórios de RH: a API estadual (SIARH) é lenta demais para consulta em tempo real, então sincronizo servidores, dependentes e remunerações com o PostgreSQL em tasks Celery agendadas e idempotentes.
  • Avaliação do atendimento: totem Android em React Native, API Node/Express e dashboard React com exportação em PDF e Excel, implantados em Docker.
  • Auditoria de folha: automações em pandas, openpyxl e Selenium que cruzam a folha com as tabelas de reajuste de mais de 2.000 servidores, com cálculos monetários em Decimal.

Dizevolv

Engenheiro de Software

ago/2026 → out/2026

São Luís, MA · SaaS do zero

SaaS multi-tenant para os setores jurídico, previdenciário e imobiliário, desenvolvidos em esteira agêntica com Spec Kit.

  • Plataforma jurídica com LLMs e RAG: orquestrei buscas numa API de terceiros com Celery (submissão, polling com task.retry(countdown=…) e controle de cota). Uma task periódica reenfileira os jobs que ficam presos quando um worker morre.
  • Serverless em Deno: webhook do WhatsApp com abstração de provedor (Evolution API e Meta), assistente com ferramentas e RAG, e tela para um humano assumir a conversa e devolvê-la à IA. Contratos validados com Zod.
  • Resiliência: deduplicação por ID da mensagem (entrega at-least-once), retry em 429/503/529 e consumo de tokens rastreado, com cota por escritório.
  • CRM imobiliário: serviço operacional e de super admin separados, cada um com banco e chaves JWT próprios. Endpoints idempotentes via Idempotency-Key com select_for_update, e CI que barra o deploy se falhar o teste de isolamento de tenants.

Desenvolvedor Backend

  • Observabilidade e qualidade: Sentry (Django, Celery, Beat, tracing) com alertas no Slack por ambiente e severidade. Escrevi mais de 170 testes.
